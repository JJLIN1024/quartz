- 溝通與合作
	- 在開始實作之前，確實釐清 SPEC，且對 SPEC 要提出質疑
	- 在開始實作之前，先想好大略解決方案，找相關人士討論，看看方向是否正確
	- 開始實作後，每一個和開始實作之前不一樣的改動都要切成 commit，以讓 code review 有效率為原則
	- 在 Code Review 之前先幫自己 Code Review 一次
